# flowkeep-releases

Auto-update distribution for [FlowKeep](https://flowkeep.dev).

This repository is managed by CI — do not edit manually.

| File | Purpose |
|---|---|
| `appcast.xml` | Sparkle auto-update feed (read by the app) |
| `FlowKeep-x.x.x.dmg` | Versioned release asset |
| `FlowKeep.dmg` | Stable-name asset — always the latest version |

**Install guide:** https://flowkeep.dev/download
